# GitHub banner, design spec (2026-10-09)

Two images from one design, in the app's claymorphism system (see `2026-10-07-filehound-uiux.md`):

| Output | Size | Where it goes |
|---|---|---|
| `docs/banner/social-preview.png` | 1280×640 | Repository settings → Social preview (uploaded by hand; GitHub crops to ~1200×600, so everything stays inside x 80–1200, y 40–600) |
| `docs/banner/readme-banner.png` | 1600×500 | Top of `README.md`, above the H1 |

Pipeline: the illustration is generated by Higgsfield `nano_banana_pro` with `assets-src/hound-hero.png` as the character reference (`tools/assets/banner.ps1`); the text is composited afterwards in Pillow with Segoe UI (`tools/assets/banner_compose.py`) so it is crisp and exactly on-palette. The generated image carries no text.

## Concept

Hound sits on the right, holding his butter magnifying glass up in one paw while lifting a rescued cream envelope-file (peach ribbon, as in `hound-found`) out of a tipped mint recycle bin with the other. Pastel clay files float around him as if just found. Magnifier = search, bin + lifted file = recovery. The text sits on empty cream to the left, so the eye reads wordmark, then tagline, then the hound doing what the tagline says.

## Composition

Shared: flat Canvas `#FBF4EA` full-bleed; a soft peach radial glow `#F9D3C0` behind the character only (echo of the dashboard hero card); shadows warm `#8C6E55` at 14%, never grey-black. The text zone stays pure cream.

**Social 1280×640.** 12-column grid, 96 px gutters. Text block columns 1–6 (x 96–640); illustration columns 7–12. Mascot centre (920, 345), ~470 px tall, facing left. Bin at his lower left. Props: Mint folder (700, 150), Butter document (1135, 130), Lilac frame (1150, 425), Sky drive (725, 470); nothing crosses x < 660.

**README 1600×500.** Rounded card, radius 40, fill `#FBF4EA`, 1 px white rim at 60% on the top edge, transparent corners, no outer shadow (it would show on GitHub's dark theme). Mascot centre (1180, 262), ~400 px tall. Props: Mint folder (960, 95), Butter document (1440, 80), Lilac frame (1470, 400), Sky drive (975, 420); nothing crosses x < 880.

## Text overlay

Strings: wordmark `FileHound`; tagline `Find any file on any drive as you type.` / `Bring deleted ones back.`; chips `Open source` · `Windows 11` · `.NET 10`.

| Element | 1280×640 | 1600×500 |
|---|---|---|
| Wordmark, Segoe UI Bold, Ink `#3F3A36`, tracking −2 px | 96 px at (96, 184) | 88 px at (88, 128) |
| Tagline, Semibold, Ink | 34 px, lines at y 310 / 354, max width 560 | 30 px, y 236 / 274, max width 600 |
| Chip row | y 426, x 96; pills 36 high, radius 18, padding 16, gap 10 | y 336, x 88; pills 34 high, radius 17, padding 14, gap 10 |
| Chip text, Semibold, InkSoft `#7A716A` on Surface `#FFFBF5` | 18 px | 17 px |

PeachDeep `#EE8F6E` is 2.2:1 on cream, so no word uses it; it appears only as a 6 px rounded underline bar (120 px wide) under the wordmark and as the paw glyph in the first chip. Contrast: Ink on cream 10.3:1; InkSoft on the pill 4.7:1 (AA at 17–18 px).

## Prompts

Both start with the `$mascotStyle` sentence from `tools/assets/generate.ps1`, then the pose:

> Sitting three-quarter view, body turned toward the left of the frame, holding the big round butter-yellow magnifying glass up in the right paw, and with the left paw lifting a rescued cream envelope-shaped file with a peach ribbon out of a small pastel mint clay recycle bin whose cream lid is tipped open beside him, tail up, delighted expression, tongue out, three tiny butter-yellow clay sparkles. Floating gently around him, four small puffy clay objects: a mint green file folder with cream paper peeking out, a butter yellow document page with a folded corner, a lilac picture frame with a tiny pastel mountain, a periwinkle blue hard drive with a mint status light. Soft warm peach glow (#F9D3C0) behind the character only. Gentle warm contact shadows, no grey shadows.

- Social: `--aspect_ratio 16:9`, "the character and all objects occupy only the right 45% of the frame; the left 55% is completely empty, plain flat solid cream (#FBF4EA)". Crop the centre band to 1280×640.
- README: `--aspect_ratio 21:9` (a 3.2:1 crop keeps 69% of the frame, so the model composes for width), "right 42% / left 58% empty". Crop the centre band and scale to 1600×500.
- Both end with "No text, no letters, no logo, no watermark."

## Fallbacks

1. **Kit-bash.** Generate the pose alone on cream and the props on white, remove backgrounds, and composite in Pillow at the positions above, drawing the warm shadow and the peach glow in code. Default if a render puts anything left of x 660 / 880.
2. **Crop and extend.** If the right side is good but the model drew text or spilled into the text zone, crop the clean band and paint the rest `#FBF4EA`; the background is flat, so a plain fill extends invisibly.
